# FileForge 1.9 — пълна версия за нов GitHub акаунт

Това е **пълен комплект с всички файлове** за ново, празно GitHub repository `fileforge`.
Не е нужно да имаш компютър, платен план, сървър или Android Studio.

## 1. Качване само през Android

1. Изтегли от разговора `FileForge-1.9-FULL-new-account.zip`.
2. Отвори Files by Google → Downloads → намери ZIP → Extract (Разархивирай).
3. Влез в **новия** GitHub акаунт в Chrome и отвори https://github.com/new .
4. Repository name: **fileforge**. Visibility: **Public**. Не добавяй README чрез отметката на GitHub.
5. Избери **Create repository**.
6. В празното хранилище избери **uploading an existing file** или **Add file → Upload files**. Ако не виждаш възможността, включи Chrome ⋮ → Desktop site.
7. Качи **всички разархивирани файлове** в главната папка. Качват се файловете, НЕ самият ZIP. Всичко като `index.html` и `multi-file.html` трябва да е на едно ниво, без допълнителна подпапка.
8. Натисни **Commit changes**.
9. В GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
10. Отвори `https://НОВОТО-ТИ-ИМЕ.github.io/fileforge/` в Chrome. Замени `НОВОТО-ТИ-ИМЕ` с новия GitHub username.
11. Провери основните функции. След това инсталирай PWA: Chrome ⋮ → Add to Home screen → Install app.

Файлът `.nojekyll` е незадължителен. Ако Android не показва скритите файлове, може да го пропуснеш.

## 2. Какво съдържа

- Images: JPG/PNG/WEBP, Resize, Crop, Rotate, Adjust, Compress.
- PDF Studio: Images → PDF, Merge, Split, Organise и миниатюри (когато PDF.js е наличен).
- ZIP & Archives: създаване, отваряне, извличане.
- Batch Images: пакетна обработка на снимки.
- Audio Studio: Trim, Volume, Fade, WAV export.
- Video Studio: кадри, storyboard, кратък WebM запис със или без аудио (при поддръжка от браузъра).
- Downloads & Sharing: директни HTTPS файлови линкове с CORS ограничения; Android Share.
- File Desk: автоматично разпознаване и отваряне в подходящ инструмент.
- Results: преглед, изтегляне, избрани локално запазени резултати; търсене, филтри и ZIP на запазените.
- Multi-File Actions: снимки → PDF, обединяване на PDF и създаване на ZIP от няколко файла. Отваря се от началния екран и Tools.

## 3. Важно за данните от старата версия

**Не изтривай старата FileForge PWA**, преди да си изтеглил нужните файлове и резервно копие.

Новият GitHub акаунт означава **различен интернет адрес (origin)**. Историята и настройките от стария сайт **няма да се появят автоматично** в новия.

- В старата PWA отвори Settings / History и направи **JSON Backup** (история и любими инструменти).
- Изтегли важните готови файлове на телефона. JSON Backup **не включва** PDF, снимки, ZIP, видео/аудио резултати или локално запазените IndexedDB файлове.
- След отваряне на новата PWA използвай **History → Import backup** за данните, които този формат поддържа.
- Инсталирай новата PWA едва след тестовете. Старото приложение остава независимо.

## 4. Какво е проверено

- JavaScript синтаксис на всички файлове.
- Няма повтарящи се HTML `id` или липсващи локални JS файлове.
- Браузърни тестове на мобилния интерфейс, основните раздели и навигацията.
- Реална обработка на тестова PNG снимка: генериране на резултат и показване в Results.
- Multi-File Actions: реален ZIP от два файла; ZIP-ът е отворен и съдържа правилните байтове.

Остава за проверка на твоя Android: инсталиране от новия GitHub Pages адрес, реален PDF експорт чрез външната библиотека, Service Worker кеширане и Share менюто.

## 5. Технически бележки

- Изходният код е компактен статичен PWA — GitHub Pages го публикува **без компилация**.
- Работи с относителни URL адреси и не изисква да пишеш username в кода.
- `pdf-lib` и PDF.js се зареждат от CDN при първо ползване и може да изискват интернет.
- ZIP библиотеката `jszip.min.js` е включена локално със своя лиценз `JSZIP-LICENSE.txt`.
- Няма връзка с платени API; няма облачно качване на личните файлове.
- Приложението не е универсален YouTube downloader или конвертор на всяко видео в MP4.
- `fileforge-saved-results-v1` е отделна IndexedDB база; нейното съдържание не е в JSON Backup.

**Произход на пълния пакет:** сглобен е от последния наличен цялостен изходен комплект на FileForge 1.3, модул Saved Results от 1.5 и добавката Multi-File Actions от 1.8, с корекции, интеграция и единна версия 1.9. Възможно е отделни експериментални изменения от старото repository да не са възстановени буквално; затова проверявай функциите, преди да спреш да използваш старата версия.
